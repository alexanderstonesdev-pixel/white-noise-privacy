# White Noise: Relax &amp; Sleep — Privacy Policy

This repository hosts the privacy policy for the Android app
**White Noise: Relax &amp; Sleep** (`com.alexanderstones.rumoribianchi`).

**Live policy:** https://alexanderstonesdev-pixel.github.io/white-noise-privacy/

The policy is a single static page (`index.html`), in Italian and English. It is
served via GitHub Pages so that it has a stable, public URL for the Google Play
Store listing and the Play Console Data Safety form.

There is no code and no tracking in this repository — it exists only to publish
the document.
